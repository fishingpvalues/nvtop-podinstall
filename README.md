# nvtop-podinstall

One-command install in Ubuntu/Debian pod:

```bash
curl -fsSL https://raw.githubusercontent.com/fishingpvalues/nvtop-podinstall/main/i.sh | bash
```

Install only:

```bash
curl -fsSL https://raw.githubusercontent.com/fishingpvalues/nvtop-podinstall/main/i.sh | bash -s -- --install-only
```

Run UI (TTY):

```bash
curl -fsSL https://raw.githubusercontent.com/fishingpvalues/nvtop-podinstall/main/i.sh | bash -s -- --run
```
